# Ветки

## основные ветки:

- main (стабильная версия)
- develop (общая рабочая ветка back и front)

## правила создания веток

хотелось бы придерживаться неких конвенций по поводу названия новых веток `тип/область-кратко-что-делаем`.\
к типам относятся:

- `feature/` (для разработки новых функций)
- `bugfix/` (для исправления ошибок)
- `hotfix/` (для исправления критических ошибок, непосредственно из `main`)
